The Addon MyAlterEgo is a Alt Overview Addon for all ur Charakter in World of Warcraft Project Ebonhold.
- U can see all your Tokens, Soul Ashes, Lost Orbs, Classes, Gold, Item level, Character Name, Locked ID´s for Raids and Dungeon.
- Open it with left click on Minimap Button for the Overview or write /myego in the chat. Right click on Minimap Button u open the Config Menu.
